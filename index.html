Выбираем два простых числа p и q: p = 17
q = 19

Выбираем число e такое, что:
– 1 < e < φ(n)

– e и φ(n) взаимно простые (их НОД = 1)

Попробуем e = 5 → НОД(5, 288) = 1 → ✅ подходит!
Считаем φ(n) = (p−1)(q−1)

φ(n) = (17−1) × (19−1) = 16 × 18 = 288

Находим закрытый ключ d
Нужно найти такое число d, чтобы: (e × d) mod φ(n) = 1

У нас: e = 5, φ(n) = 288
Ищем d такое, что (5 × d) mod 288 = 1

Проверяем:

d = 173 → 5 × 173 = 865 → 865 mod 288 = 1 ✅
Значит, d = 173

Формируем ключи RSA:

Открытый ключ: (n, e) = (323, 5) → им можно зашифровать сообщение

Закрытый ключ: (n, d) = (323, 173) → им можно расшифровать сообщение

Зашифруем сообщение
Пусть сообщение m = 42 («42» = «анализ готов»)
Условие: m должно быть меньше n → 42 < 323 → ✅

Формула шифрования:
C = me mod n = 425 mod 323 = 130691232 mod 323 = 111
→ Шифротекст C = 111

Расшифруем сообщение
M = Cd mod n = 111173 mod 323 = 42
Исходное сообщение восстановлено! ✅
